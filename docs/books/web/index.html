mvsMF (mvsmf) for MVS 3.8j

The z/OSMF REST API for MVS 3.8j, a CGI module of the HTTPD web server. It serves data sets, UFS files, jobs and console commands to clients such as curl, Zowe CLI and Zowe Explorer. Two books describe mvsMF 1.4.
